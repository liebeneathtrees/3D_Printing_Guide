N01 / 13 — Introduction

Welcome to the guide

Everything you need to run an Ender 3 Pro on Klipper, tuned with real settings and a clear path from Creality Print to OrcaSlicer.

This guide is written for one specific setup: an Ender 3 Pro running Klipper firmware, controlled from a tablet instead of the printer's stock screen, currently slicing in Creality Print and looking to move to OrcaSlicer. If that's your printer, everything here is built around your exact situation rather than 3D printing in general.

You don't need prior 3D printing experience to follow along, but a little comfort with computers helps — you'll be editing config files, using a web browser to control the printer, and installing new software along the way.

How this guide is organized

The sidebar is roughly the order you'd want to work through things if you're starting fresh: understand the setup, get the hardware dialed in, calibrate it, then move into slicing and materials. But every section stands on its own — jump straight to Troubleshooting if a print just failed, or straight to Filament Care if a spool feels off.

// TIP

Keep this guide open in a second tab while you work. Most sections are meant to be followed step-by-step next to Mainsail/Fluidd or OrcaSlicer, not read cover to cover in one sitting.

A note on this being a moving target

Klipper, Mainsail/Fluidd, and OrcaSlicer are all actively developed. Menu names and exact wording can shift between versions. The concepts and workflow here will hold up even when a button gets renamed — treat this as the map, not a pixel-perfect screenshot guide.

N02 / 13 — Orientation

Your setup at a glance

Four pieces work together: the printer, the Klipper firmware, the tablet, and the slicer. Here's how they talk to each other.

Understanding this once makes almost everything else in this guide click into place — especially the OrcaSlicer migration later on.

The printer

The Ender 3 Pro itself is unchanged mechanically from a stock unit unless you know otherwise: a Bowden-style extruder, a heated bed on a Y-axis carriage, a single Z lead screw, and a small control board (the MCU) inside the base that drives the motors, heaters, and reads the sensors. That board is running Klipper's lightweight firmware, but it's not doing the thinking on its own.

Klipper: firmware split in two

Unlike stock Marlin firmware — which does all its calculations directly on the printer's small, low-power board — Klipper splits the work in half. The printer's board (the MCU) just handles motors and sensors, moment to moment. The heavy math — path planning, acceleration, the fine timing that produces smooth curves — happens on a separate, more powerful computer called the host. In your setup, the host is the tablet.

// WHY IT MATTERS

This split is why Klipper printers can do things stock Ender firmware can't: pressure advance, input shaping, and much higher print speeds with less ringing. It's also why a tablet is part of your printer now, not just a convenience — see for the payoff.

The tablet's job

The tablet runs the Klipper host software (klippy) plus two other pieces:

  • Moonraker — an API layer that sits between Klipper and everything else. It's what lets a web browser, or a slicer, talk to your printer over your home network instead of a USB cable.
  • Mainsail or Fluidd — the web-based control panel you actually look at. This is what replaced the printer's stock screen: temperature graphs, a webcam feed (if you add one), manual controls, macros, and your print queue all live here, opened in the tablet's browser.

The slicer's job

The slicer (Creality Print today, OrcaSlicer going forward) turns a 3D model into G-code — the line-by-line instructions the printer executes. This is the piece you interact with before a print ever starts: temperatures, speeds, supports, infill, and all the settings that determine whether a print succeeds. Section N06 and N07 cover the differences and the move in detail.

How a print actually happens, start to finish

  1. You slice a model in OrcaSlicer (or Creality Print) on any computer or the tablet — the slicer doesn't need to be on the tablet itself.
  2. The G-code is sent to Moonraker over your network (or copied via USB/SD as a fallback), and stored on the tablet.
  3. You start the print from Mainsail/Fluidd in the browser.
  4. Moonraker hands the G-code to Klippy, which streams low-level commands to the printer's MCU in real time.
  5. The MCU drives the motors and heaters and reports sensor data back up the same chain, which is what populates the live graphs and progress bar you see in the browser.
// TIP

If the tablet ever feels "disconnected" from the printer in Mainsail/Fluidd, the issue is almost always Moonraker or the network link — not the printer itself. Restarting the tablet's Klipper services from the web UI fixes the majority of these.

N03 / 13 — Hardware

Printer setup

The physical fundamentals that everything else — calibration, slicer settings, print quality — depends on.

If prints are already coming out reasonably well, you don't need to redo all of this. Treat it as a checklist to confirm, and a reference for when something drifts.

Frame and belts

  • Frame bolts — the aluminum extrusion frame can loosen over time, especially after moving the printer. Snug (not overtight) the corner brackets and gantry bolts periodically.
  • Belt tension — the X and Y belts should be firm enough to give a low, tight "twang" when plucked, not a dull thud. Too loose causes layer shifting and ghosting; too tight strains the stepper motors and idlers.
  • Eccentric nuts — the wheels on the X gantry and Y carriage ride on eccentric nuts that adjust how snugly they grip the extrusion rail. They should roll smoothly with no side-to-side play. Adjust with the small end wrench that came with the printer.

Bed leveling on Klipper

This is the one area where Klipper changes the workflow meaningfully from stock firmware. Klipper distinguishes between two related but different things:

Z-offset

How close the nozzle sits to the bed at the "zero" point. This is set once and rarely touched, using PROBE_CALIBRATE (if you have a probe) or a manual paper-feeler check against the bed for a manual-leveling setup, then saved with SAVE_CONFIG.

Bed mesh

The Ender 3 Pro's bed isn't perfectly flat — it dips and bows slightly across its surface. Klipper can measure that variation and compensate for it automatically during a print. If you don't have an auto-leveling probe, this typically means manually adjusting the four corner knobs first to get the bed roughly level, then running BED_MESH_CALIBRATE, which walks the nozzle around the bed (at set points) prompting you to check clearance, or does it automatically if a probe is installed.

!! COMMON MISTAKE

Bed mesh compensates for a slightly uneven bed — it does not fix a bed that's grossly out of level. Always do a rough manual level with the corner knobs first, even with a mesh in place.

First-layer check

After leveling, the most reliable real-world test is a first-layer squish check: start a print and watch the first layer go down. It should look like flattened ribbon with lines just touching each other — not gapped (too high) and not rippled/translucent with dragging (too low).

  • Confirm printer.cfg matches your hardware

    If the tablet setup was inherited or configured a while ago, open printer.cfg (from Mainsail/Fluidd's config editor) and sanity-check that the board type, thermistor types, and steps-per-mm for each axis match your actual hardware. This is usually a "check once and forget it" step.

  • Level the bed manually

    Home the printer, move the nozzle to each corner, and adjust the bed knobs until a sheet of paper drags with slight resistance at each point.

  • Set Z-offset

    Run PROBE_CALIBRATE if you have a probe, or manually paper-test the center point and save with G-code offset commands, then SAVE_CONFIG.

  • Run a bed mesh

    BED_MESH_CALIBRATE, then SAVE_CONFIG. Re-run this every so often, or whenever prints start showing inconsistent first layers.

  • Print a first-layer test

    A simple large single-layer square or a calibration cube. Adjust Z-offset in small increments (0.02–0.05mm) if the squish looks wrong.

    Calibration

    Where Klipper starts to earn its keep. These are worth doing once properly, then revisiting only when something changes (new nozzle, new filament brand, hotend swap).

    PID tuning

    PID tuning teaches the firmware exactly how your specific hotend and bed heat up and hold temperature, instead of guessing. Without it, temperatures tend to overshoot and oscillate. Run these from the Mainsail/Fluidd console:

    • PID_CALIBRATE HEATER=extruder TARGET=210 (set the target to a temperature you actually print at)
    • PID_CALIBRATE HEATER=heater_bed TARGET=60
    • Save the results with SAVE_CONFIG — this writes the values into printer.cfg automatically.

    E-steps (extruder calibration)

    Confirms the extruder motor moves exactly as much filament as it's told to. Mark filament 120mm from the extruder's entry point, extrude 100mm through the console, then measure what's left. If it's off, the steps-per-mm value in printer.cfg needs a proportional adjustment. This one is usually fine on stock hardware and only worth re-checking after an extruder upgrade.

    Flow rate / extrusion multiplier

    Fine-tunes how much plastic comes out relative to what the slicer commands, correcting for small real-world variance between filament brands and diameters. OrcaSlicer has a dedicated, guided flow-rate calibration test built in — this is one of the concrete upgrades you gain by moving off Creality Print, covered in N07.

    Pressure advance — the Klipper-exclusive win

    This is the calibration most worth caring about. When the extruder speeds up or slows down, pressure builds and releases in the molten filament with a slight delay, causing blobby corners and inconsistent extrusion at direction changes. Pressure advance predicts that delay and compensates for it in real time — something stock Marlin firmware can't do at all.

    OrcaSlicer includes a built-in pressure advance test pattern that prints a small tower or line pattern across a range of values, letting you visually pick the cleanest one and drop it straight into your slicer profile per-filament. This is covered step by step in N07.

    Input shaping (optional, hardware-dependent)

    If an accelerometer has been added to the setup (not stock on an Ender 3 Pro), Klipper can measure the printer's resonant frequencies and automatically reduce ringing/ghosting at higher speeds via SHAPER_CALIBRATE. If you're not sure whether one's installed, it probably isn't — this is a nice-to-have, not a requirement.

    Retraction tuning

    Controls stringing between separate parts of a print. Tuned per-filament rather than per-printer — covered together with material settings in N08, and OrcaSlicer's built-in retraction test tower makes this fast to dial in.

    // TIP

    Do these roughly in order: PID → E-steps → bed mesh (N03) → pressure advance → retraction. Each one assumes the previous is already reasonably correct.

    N05 / 13 — Hardware

    Upgrade path

    Stock Ender 3 Pro + Klipper is already capable. These are the upgrades worth considering, roughly in the order they tend to pay off — and what each one actually buys you.

    None of this is required. A well-tuned stock machine (see N03 and N04) prints well. Treat this section as a menu, not a checklist — pick upgrades that solve a problem you actually have, or that move you toward a specific goal like the "walk up and print" feel of a Bambu-style machine.

    // TIP

    Buy upgrades to solve problems you've actually hit, not problems you've read about. A stock, well-calibrated Ender 3 Pro will outprint a poorly-set-up upgraded one every time.

    Tier 1 — Automate bed leveling

    The single highest-value upgrade for day-to-day convenience. Replaces manual corner-knob leveling with a probe that measures the bed automatically and feeds a mesh into Klipper on every print.

    OptionCostNotes
    BLTouch / CR TouchLowThe standard choice — inexpensive, well documented, huge community support for Ender-series printers
    Eddy-current probe (BTT Eddy, Cartographer)Moderate–HighFaster and more precise than a BLTouch; some models can also assist with resonance testing. Overkill for a first upgrade

    Once installed, wire it into a PRINT_START macro so bed mesh calibration runs automatically at the start of every print — no manual command needed. Combine with Klipper's adaptive mesh (built into current Klipper versions) or the KAMP macro set, which shapes the mesh to only the area actually being printed, making it faster than meshing the whole bed every time.

    Tier 2 — Input shaping

    Reduces ringing/ghosting near sharp corners and unlocks meaningfully higher print speeds without quality loss.

    • ADXL345 accelerometer (~$15–20) mounted to the toolhead, temporarily or permanently.
    • Run Klipper's SHAPER_CALIBRATE once per axis to measure resonant frequencies and pick the best shaper.
    • Klippain Shake&Tune is worth installing alongside this — it automates the test sequence and produces clear graphs, taking most of the guesswork out of reading the results.

    This is usually a one-time calibration (redo it after major mechanical changes), not something that needs to run before every print.

    Tier 3 — Smarter macros

    Software, not hardware — and often the highest value-per-hour upgrade on this whole list.

    • A proper PRINT_START macro that chains homing → bed mesh → heating → priming into one automatic sequence, so starting a print from OrcaSlicer is genuinely one click.
    • KAMP for adaptive meshing and adaptive purge lines.
    • A matching PRINT_END macro that parks the head, retracts, and turns off heaters consistently.

    Tier 4 — AI print monitoring

    A webcam plus Obico (free, open-source) adds AI-based failure detection — catching spaghetti or detachment early and optionally pausing the print — similar in spirit to the automatic error detection built into higher-end machines. Also gives you remote viewing of prints in progress.

    Tier 5 — Mechanical quality-of-life

    Upgrades that improve print quality or reliability directly, independent of Klipper:

    • All-metal hotend — enables higher temperatures for materials like ABS and opens the door to more exotic filaments.
    • Direct-drive extruder conversion — significantly improves retraction performance and flexible-filament printing (TPU) compared to the stock Bowden setup, at the cost of added mass on the toolhead.
    • PEI spring-steel sheet or glass bed — more consistent, easier-release bed surface than the stock sticker-coated plate.
    • Dual gear extruder / upgraded stock extruder — better grip on filament, fewer skipped-steps under-extrusion issues.
    • Capricorn PTFE tubing — tighter tolerance Bowden tube, reduces friction and improves retraction consistency on a Bowden setup.

    Tier 6 — Speed and rigidity

    Bigger, more involved mods aimed at pushing print speed well beyond stock territory. Only worth considering once tiers 1–3 are in place — speed upgrades expose problems that calibration and a solid frame would otherwise hide.

    • Dual Z-axis / Z-axis brace — reduces Z-wobble, particularly noticeable on taller prints.
    • Linear rails — replace the stock wheel-on-extrusion carriages for smoother, more precise motion at speed. A significant mechanical project, not a quick swap.
    • Stiffer frame bracing — corner brackets, gantry braces — reduces flex that shows up as artifacts at higher acceleration.

    Tier 7 — Environment control

    • Enclosure — improves ABS printing significantly by reducing drafts and warping; also helps hold ambient temperature steady for any material.
    • Dedicated filament dryer — covered in N09; pairs naturally with an enclosure setup but is independently useful either way.

    Where this leaves you vs. a Bambu-style machine

    Tiers 1–4 get an Ender 3 Pro remarkably close to the "walk up and print" feel of an integrated machine like a P2S — automatic leveling, automatic meshing, tuned motion, and AI monitoring are all genuinely achievable. The one piece that stays manual is automatic flow/pressure-advance calibration: that relies on a dedicated sensor Bambu builds into their toolhead, and there isn't a widely-adopted Klipper equivalent. OrcaSlicer's guided calibration tests (N07) make this fast, but it remains a "print a pattern, look at it, pick a value" process rather than a fully automatic one.

    N06 / 13 — Slicing

    Creality Print vs OrcaSlicer

    Both are capable slicers. The honest case for switching, and what you give up.

    Creality Print isn't a bad slicer — it's built on solid open-source slicing engines and it's genuinely easy to get started with, especially on Creality's own hardware. But it's optimized for a Creality-first, mostly stock-firmware audience, and a Klipper setup outgrows it fairly quickly.

    ◆ Creality Print

    • Pro: simple, guided setup with printer profiles that "just work" out of the box on Creality hardware.
    • Pro: low learning curve — good for a first slicer.
    • Pro: integrated model repair and a clean, uncluttered interface.
    • Con: limited Klipper-specific tooling — no built-in pressure advance, flow, or input-shaper calibration workflows.
    • Con: fewer advanced supports options (no tree/organic supports in most versions).
    • Con: slower update cadence and smaller community than the OrcaSlicer/Bambu-lineage ecosystem.
    • Con: less granular control over per-feature speeds, cooling, and multi-material settings.

    ◆ OrcaSlicer

    • Pro: built-in, guided calibration tests — flow rate, pressure advance, retraction, temperature towers — designed with Klipper printers specifically in mind.
    • Pro: excellent organic/tree supports and more granular per-object, per-part settings.
    • Pro: active development, large community, frequent updates, strong Moonraker network-printing integration.
    • Pro: more precise control over cooling, speed, and pressure advance per filament profile.
    • Con: steeper learning curve — many more settings visible by default.
    • Con: initial printer profile setup is more manual since it's not a Creality-branded tool.

    The practical read

    For a beginner's very first prints, Creality Print's simplicity is genuinely valuable. But once a Klipper setup is dialed in and the interest is in print quality and speed — which pressure advance and proper calibration directly improve — OrcaSlicer's tooling is a clear step up, and it's purpose-built for exactly the printer stack described in this guide.

    Setup difficultyLowModerate
    Klipper calibration toolsNone built-inFlow, pressure advance, retraction, temp tower
    SupportsStandardStandard + tree/organic
    Network printing via MoonrakerLimitedNative, well supported
    Update frequencySlowerFrequent

    N07 / 13 — Slicing

    Migrating to OrcaSlicer

    A smooth path from Creality Print, keeping the settings that already work and picking up the calibration tools that don't exist there.

  • Before you switch: write down your current settings

    In Creality Print, note your dialed-in nozzle/bed temps, print speed, retraction distance and speed, and any cooling fan tweaks per filament you actually use. You won't reuse these blindly, but they're a known-good starting point instead of factory defaults.

  • Install OrcaSlicer

    Download it from the official OrcaSlicer GitHub releases page and install like any other application. It can run alongside Creality Print — no need to uninstall anything yet.

  • Add your printer profile

    On first launch, use the setup wizard and search for "Ender 3 Pro" (or "Creality Ender 3") in the printer list to get correct bed size and basic kinematics. Since you're on Klipper, double-check the machine's start/end G-code area next — see step 5.

  • Connect OrcaSlicer to the printer over your network

    In the printer settings, look for a device/connection tab and enter the tablet's IP address plus the Moonraker API key (found in Mainsail/Fluidd's settings). This lets you send sliced files straight to the tablet without touching a USB drive.

  • Check start/end G-code against your Klipper macros

    If printer.cfg already defines macros like START_PRINT / END_PRINT (common in Klipper setups that handle homing, bed mesh, and priming automatically), OrcaSlicer's start G-code should simply call that macro rather than duplicating homing and leveling commands itself. Duplicated logic here is the single most common cause of odd behavior right after a slicer switch.

  • Carry over your working temps and speeds

    Plug in the numbers you wrote down in step 1 as your starting filament profile in OrcaSlicer. They'll likely need small nudges, not a full redo.

  • Run OrcaSlicer's calibration tests

    Under the Calibration menu: run flow rate, then pressure advance, then a retraction test, in that order, per filament type you use regularly. Save the results into each filament profile — this is the payoff for switching. See N04 for why each of these matters.

  • Do a side-by-side first print

    Slice the same model you'd normally print in both slicers once, just to compare. It's the fastest way to build confidence that the migration preserved (or improved on) your existing quality.

    • !! WATCH FOR

    If prints after switching show a slight blob or pause at the very start, it's almost always leftover priming/purge G-code from OrcaSlicer's default start script conflicting with a Klipper macro that already primes the nozzle. Check step 5 first.

    // TIP

    You don't have to switch all at once. Keep Creality Print installed and treat the first few weeks in OrcaSlicer as a parallel trial — nothing about Klipper or the printer needs to change to support running both.

    Filament types & settings

    Starting points, not gospel — always sanity-check against what's printed on your specific spool.

    MaterialNozzle °CBed °CCooling fanDifficultyGood for
    PLA195–21550–60High (100%)EasyGeneral models, prototypes, decorative prints
    PETG230–25070–80Low–Medium (30–50%)ModerateFunctional parts, outdoor use, mechanical fits
    ABS230–25095–110Off or very lowHarderHeat-resistant parts, enclosure recommended
    TPU210–23040–60Medium (40–60%)Moderate–HardFlexible parts, gaskets, phone cases

    PLA

    The default for good reason: forgiving temperatures, minimal warping, no enclosure needed, and it sticks to a bare or lightly-prepped bed easily. Best starting material and still fine for most non-functional prints even once you're experienced.

    PETG

    Tougher and more heat-resistant than PLA, with a tendency to string more and to bond almost too well to certain bed surfaces (a thin layer of glue stick or a dedicated PETG-friendly plate helps release). Slightly more sensitive to moisture than PLA — see N09.

    ABS

    Stronger and more heat-tolerant than PLA or PETG, but prone to warping and layer splitting from drafts and temperature swings, since an Ender 3 Pro has no enclosure by default. A simple draft shield (even a cardboard box) makes a meaningful difference. Ventilate the room — ABS fumes are more noticeable than PLA's.

    TPU

    Flexible filament — genuinely fun once dialed in, genuinely frustrating before that. Print slowly (well under typical PLA speeds), keep retraction short if using it at all, and expect a Bowden setup like the Ender 3 Pro's to be pickier with TPU than a direct-drive printer would be. Very moisture-sensitive — see N09 before printing a spool that's been open a while.

    N09 / 13 — Materials

    Filament care & storage

    Humidity is the quiet cause behind a large share of "mystery" print failures. This section is about preventing that before it starts.

    Why humidity is the enemy

    Most 3D printing filaments are hygroscopic — they pull moisture out of the air over time, even indoors. Once that moisture is absorbed into the plastic, it turns to steam the instant it hits the hotend, and that steam has to go somewhere. The result shows up as print defects that look unrelated to filament at first glance:

    • Popping or crackling sounds while printing — the clearest audible sign.
    • Stringing and oozing that gets worse over time even with retraction correctly tuned.
    • Rough, matte, or bubbly surface texture instead of a smooth finish.
    • Weak layer adhesion — parts that snap or delaminate more easily than they should.
    • Inconsistent extrusion that looks like an under-extrusion problem but isn't.
    // SEE ALSO

    If you're troubleshooting any of the symptoms above, check — but if a spool has been open for a while, come back here first.

    Material sensitivity, ranked

    Not all filaments absorb moisture at the same rate — worth knowing so you don't over-invest in protecting PLA or under-invest in protecting TPU.

    • Most sensitive: TPU, nylon — absorb moisture fast, sometimes within a day or two of open-air exposure in humid conditions.
    • Moderately sensitive: PETG — noticeably more sensitive than PLA, especially prone to visible popping when wet.
    • Least sensitive (but not immune): PLA, ABS — more forgiving, can sit out longer, but will still degrade over weeks to months.

    Storage methods

    MethodCostGood for
    Resealable bag + desiccantVery lowOccasional-use spools, short-term storage between prints
    Vacuum-seal bag + desiccantLowLonger-term storage, spools you won't touch for weeks
    Dry box (airtight container + desiccant)Low–ModerateEveryday spool storage between print sessions, easy to grab and go
    Active filament dryerModerateDrying out already-wet spools, printing moisture-sensitive materials (TPU, nylon, PETG) directly from a dry, heated box

    A reasonable setup for this printer: keep the spool currently loaded in a basic dry box or sealed container with desiccant at all times when not actively printing, and reserve a dedicated dryer (or drying cycles) for TPU, nylon, and any spool that's shown early signs of moisture pickup.

    Desiccant strategy

    • Silica gel with a color indicator is the easiest to manage — orange/blue beads turn green/pink (formulation-dependent) when saturated, giving a clear visual cue instead of guesswork.
    • How much: more surface area of desiccant beats a small packet — a wide, shallow tray or several bags spread around the spool works better than one small sachet.
    • Recharging silica gel: most reusable silica gel can be dried out in a home oven at a low temperature (roughly 100–120°C / 212–250°F) for 1–2 hours, spread thin on a tray, until it returns to its "dry" color. Let it cool before returning it to the container.
    • Replace vs. recharge: silica gel can be recharged many times; only replace it once it stops changing color reliably after a recharge cycle.

    Drying filament that's already wet

    If a spool is showing popping, stringing, or a rough finish and it's been stored loosely, dry it before troubleshooting anything else on the printer or in the slicer.

    MaterialDry tempTypical time
    PLA40–45°C4–6 hrs
    PETG55–65°C4–6 hrs
    ABS55–65°C2–4 hrs
    TPU45–50°C6–8 hrs
    !! CAUTION

    A dedicated filament dryer or food dehydrator with an accurate thermostat is the safest tool for this. A home oven can work in a pinch for some materials but is much harder to hold at a precise low temperature, and overshooting can warp the spool itself or soften filament onto it — go low and check often if that's the only option available.

    A simple ongoing habit

    • Store the spool currently on the printer in a dry box or sealed bag with desiccant whenever it's not actively printing overnight or for more than a day.
    • Keep a hygrometer inside one storage container as a general gauge — under roughly 30% relative humidity is a reasonable target.
    • Check desiccant color before starting any print with PETG, TPU, or nylon.
    • If a spool sits untouched for more than a couple of weeks, assume it needs a quick dry cycle before the next print rather than finding out mid-print.
    N10 / 13 — Working with files

    File types & workflow

    Three file types, three jobs. Knowing which one you're holding avoids a lot of confusion.

    FormatWhat it isWhen you touch it
    .STLRaw 3D geometry — just the shape, no printer settings, no color/material info.Downloaded models, exported from CAD software, before slicing.
    .3MFA project format that bundles geometry with slicer settings, plate arrangement, supports, and (in OrcaSlicer) multi-part or multi-color setup.Saving/reopening a project you want to reprint or tweak later with all settings intact.
    .gcodeThe final, sliced machine instructions — exact toolpaths, temperatures, and speeds, specific to the settings used to generate it.The file actually sent to the printer to print.

    The typical workflow

    1. Get a model as an .STL (or sometimes .STEP/.OBJ from CAD sources) from a model repository or your own design software.
    2. Open it in OrcaSlicer, position and orient it, apply supports if needed, and set your filament/print profile.
    3. Optional but recommended: save the arrangement as a .3MF project file if it's something you'll print again or want to revisit — this preserves everything, not just the shape.
    4. Slice it, producing a .gcode file.
    5. Send the G-code to the printer — either directly over the network to Moonraker (fastest, no removable media involved), or via USB/SD card as a fallback if the network connection is down.
    6. Start the print from Mainsail/Fluidd on the tablet.
    // TIP

    Get in the habit of saving a .3MF alongside the .gcode for anything you might print more than once. Re-slicing from a bare .STL later means redoing supports and placement from scratch; reopening a .3MF restores everything instantly.

    Organizing project files

    A simple folder structure avoids a lot of "which settings did I use for this?" confusion later:

    • Keep source .STL files separate from sliced output.
    • Save the .3MF project next to (or instead of) the raw STL once you've dialed in a print.
    • Name G-code files with the material and date if you experiment with settings often — e.g. bracket_petg_v2.gcode — so Mainsail/Fluidd's file list stays meaningful weeks later.

    Elephant's foot (bulging first layers)Z-offset too low, bed too hot for the materialN03 (Z-offset)
    Ringing / ghosting near sharp cornersPrint speed/acceleration too high, loose belts, no input shapingN03 (belts), N04 (input shaping if hardware allows)
    Clogged nozzleDebris, filament residue, prolonged use without cleaningN12 (maintenance — cold pull / nozzle cleaning)
    Tablet shows "disconnected" from printerMoonraker/network hiccup, not usually the printer itselfN02 — restart Klipper services from Mainsail/Fluidd
    // TIP

    Change one variable at a time. If a print fails, resist adjusting temperature, speed, and retraction all at once — you'll fix the symptom but lose the information about what actually caused it.

    N12 / 13 — Keeping it running

    Maintenance

    A little regular upkeep prevents most of the failures in the troubleshooting section from happening in the first place.

    Every few prints

    • Wipe down the bed surface (isopropyl alcohol works well) to keep adhesion consistent.
    • Check that the filament path is clear and the spool feeds smoothly without snagging.

    Monthly-ish

    • Check belt tension on X and Y — retighten if it's gone slack.
    • Check eccentric nuts for wheel play on the gantry and bed carriage.
    • Lubricate the Z lead screw lightly (a small amount of PTFE-safe grease or lithium grease).
    • Inspect wiring at stress points — the hotend cable and bed cable flex constantly and are the most common wear points on this printer.
    • Re-check bed mesh if first layers have started looking inconsistent.

    As needed

    • Nozzle cleaning: a cold pull (heat, then let cool slightly, then pull filament through firmly) clears minor residue buildup without disassembly.
    • Nozzle replacement: brass nozzles wear down over hundreds of print-hours, especially with abrasive filaments. Swap if extrusion width or first-layer consistency degrades without an obvious other cause.
    • Klipper/Moonraker/Mainsail updates: check for updates periodically from the web UI — most issues after an update are a mismatch between components, so update Klipper, Moonraker, and Mainsail/Fluidd together rather than piecemeal.
    • Re-tension belts and re-check frame bolts after moving the printer to a new location.
    // TIP

    Most maintenance items double as troubleshooting fixes. If something in N11 doesn't have an obvious cause, work through this checklist before assuming it's a settings problem.

    N13 / 13 — Reference

    Glossary & quick reference

    Terms used throughout this guide, in one place.

    MCU
    The printer's own control board — handles motors, heaters, and sensors in real time, but relies on the host for path planning under Klipper.
    Host
    The more powerful computer running Klipper's main software — the tablet, in this setup.
    Moonraker
    The API layer connecting Klipper to web interfaces and slicers over the network.
    Mainsail / Fluidd
    The browser-based control panels used to monitor and control the printer — the replacement for the stock screen.
    Z-offset
    The nozzle's calibrated distance from the bed at the "zero" height.
    Bed mesh
    A map of small variations across the bed's surface that Klipper compensates for during printing.
    Pressure advance (PA)
    A Klipper feature that compensates for pressure buildup in the hotend during speed changes, reducing blobbing at corners.
    Input shaping
    A Klipper feature (requires an accelerometer) that reduces ringing/ghosting by compensating for the printer's resonant frequencies.
    Flow rate / extrusion multiplier
    A correction factor for how much filament is actually extruded relative to what's commanded.
    Retraction
    Pulling filament back slightly during travel moves to reduce oozing and stringing.
    G-code
    The line-by-line machine instructions a slicer produces and the printer executes.
    .3MF
    A project file format bundling model geometry with slicer settings and layout.
    Hygroscopic
    Prone to absorbing moisture from the air — true of most 3D printing filaments to varying degrees.
